# Business Rules

## BR-1: テキスト校正バリデーションルール

### BR-1.1: 空テキストチェック
- **条件**: inputText が空文字列またはホワイトスペースのみ
- **アクション**: 校正リクエストを送信しない。エラーメッセージを表示
- **エラー**: `{ type: 'EMPTY_TEXT', message: '校正するテキストを入力してください' }`
- **実行箇所**: Renderer Process（IPC 送信前）

### BR-1.2: プロバイダー設定チェック
- **条件**: activeProvider の必須設定が未入力
  - LM Studio: endpointUrl が空
  - Gemini: apiKey が空
- **アクション**: 校正リクエストを送信しない。設定画面への誘導メッセージを表示
- **エラー**: `{ type: 'PROVIDER_NOT_CONFIGURED', message: 'LLMプロバイダーの設定を確認してください。設定画面で接続情報を入力してください' }`
- **実行箇所**: Main Process（LLMService.correct() 内）

---

## BR-2: 設定バリデーションルール

### BR-2.1: LM Studio エンドポイント URL
- **フォーマット**: `http://` または `https://` で始まる URL 形式
- **バリデーション**: URL パース可能かチェック（new URL() で検証）
- **デフォルト**: `http://localhost:1234/v1`

### BR-2.2: Gemini API キー
- **フォーマット**: 空でない文字列
- **バリデーション**: 空文字チェックのみ（実際の有効性は API 呼び出し時に検証）

### BR-2.3: モデル名
- **LM Studio**: 空文字許容（LM Studio 側でデフォルトモデルが使用される場合があるため）
- **Gemini**: 空でない文字列必須。デフォルト: `gemini-2.0-flash`

### BR-2.4: プロンプトテンプレート
- **必須**: `{text}` プレースホルダーを含むこと
- **バリデーション**: テンプレート文字列に `{text}` が存在するかチェック
- **エラー**: `プロンプトテンプレートには {text} プレースホルダーが必要です`

## BR-3: エラーハンドリングルール

### エラー種別とメッセージマッピング

| ErrorType | 発生条件 | ユーザー向けメッセージ |
|-----------|---------|---------------------|
| EMPTY_TEXT | 入力テキストが空 | 校正するテキストを入力してください |
| PROVIDER_NOT_CONFIGURED | プロバイダー設定が不完全 | LLMプロバイダーの設定を確認してください。設定画面で接続情報を入力してください |
| CONNECTION_ERROR | API サーバーに接続不可 | APIサーバーに接続できません。接続先URLとサーバーの起動状態を確認してください |
| AUTH_ERROR | API キーが無効（401/403） | APIキーが無効です。設定画面でAPIキーを確認してください |
| API_ERROR | API からエラーレスポンス（上記以外） | 校正処理中にエラーが発生しました。しばらく待ってからもう一度お試しください |
| UNKNOWN_ERROR | 予期しないエラー | 予期しないエラーが発生しました。アプリを再起動してください |

### エラー判定ロジック（Main Process）
```
try {
  response = await provider.correct(text)
} catch (error) {
  if (error is network/connection error) -> CONNECTION_ERROR
  if (error.status === 401 || error.status === 403) -> AUTH_ERROR
  if (error.status >= 400) -> API_ERROR
  else -> UNKNOWN_ERROR
}
```

### エラー表示ルール
- エラーメッセージは UI 上部にバナー形式で表示
- PROVIDER_NOT_CONFIGURED の場合、「設定を開く」リンクを併記
- エラーは次の校正リクエスト成功時、または手動で閉じた時にクリア

## BR-4: プロバイダー切り替えルール

### BR-4.1: 切り替え条件
- 校正処理中（isLoading === true）はプロバイダー切り替え不可
- 設定画面での保存時に即座に切り替え

### BR-4.2: 設定保持
- プロバイダー切り替え時、各プロバイダーの設定は個別に保持
- LM Studio → Gemini → LM Studio と切り替えても、以前の LM Studio 設定は残る

### BR-4.3: 初回未設定時
- activeProvider のデフォルトは 'lm-studio'
- 未設定プロバイダーで校正実行時は PROVIDER_NOT_CONFIGURED エラー

---

## BR-5: プロンプトテンプレート管理ルール

### BR-5.1: テンプレート適用
- 校正リクエスト時、`{text}` プレースホルダーを実際のテキストに置換
- 置換は単純な文字列置換（正規表現不使用）

### BR-5.2: デフォルトリセット
- 設定画面に「デフォルトに戻す」ボタンを配置
- ハードコードされたデフォルトテンプレートに復帰

### BR-5.3: テンプレート保存
- electron-store に保存（settings.promptTemplate）
- .env でのテンプレート設定はサポートしない（複数行のため）

---

## BR-6: コピー機能ルール

### BR-6.1: コピーボタン有効条件
- 対象テキストが空でない場合のみコピーボタン有効
- 左パネル: inputText が空でない
- 右パネル: correctedText が空でない

### BR-6.2: コピーフィードバック
- コピー成功時: ボタンテキストを「コピー完了」に変更、2秒後に元に戻す
- コピー失敗時: エラーメッセージは表示しない（ブラウザ API 失敗は極めて稀）
