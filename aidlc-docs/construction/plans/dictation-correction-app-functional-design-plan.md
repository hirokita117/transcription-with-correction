## Design Questions

以下の質問に回答をお願いします。ファイル内の `[Answer]:` タグに直接回答を記入してください。

### Q1: 校正プロンプトの方針
LLM に送信する校正プロンプトはどのような方針が望ましいですか？

- A) 最小限のプロンプト（「以下のテキストの誤字脱字を修正してください」のみ）
- B) 詳細なプロンプト（言語指定、修正範囲の制限、出力形式の指定を含む）
- C) カスタマイズ可能（ユーザーが設定画面でプロンプトテンプレートを編集できる）
- D) お任せ（アプリの用途に最適なものを選択）

[Answer]: C

### Q2: テキストの文字数制限
校正対象テキストの文字数に上限を設けますか？

- A) 制限なし（LLM のトークン上限に委ねる）
- B) 適度な上限を設ける（例: 5,000文字）
- C) プロバイダーごとに異なる上限を設定
- D) お任せ（適切な制限を設計）

[Answer]: A

### Q3: 校正結果の差分表示
校正前後のテキストの差分をハイライト表示する機能は必要ですか？

- A) 不要（シンプルに左右パネルで比較するだけ）
- B) あると良い（変更箇所をハイライト）
- C) お任せ（v1 スコープを考慮して判断）

[Answer]: C

### Q4: 設定のデフォルト値
LM Studio のデフォルトエンドポイント URL はどうしますか？

- A) `http://localhost:1234/v1`（LM Studio の標準ポート）
- B) 空欄（ユーザーが必ず入力）
- C) お任せ

[Answer]: A

### Q5: コピー機能の対象
クリップボードコピーの対象はどうしますか？

- A) 右パネル（校正結果）のみにコピーボタンを配置
- B) 左パネル（入力テキスト）と右パネル（校正結果）の両方にコピーボタンを配置
- C) お任せ

[Answer]: B
